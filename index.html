Creator // PHP Ecosystem

Green PHP Framework

A modern PHP framework designed from first principles to master backend internals, clean lifecycle management, and enterprise architectural patterns.

  • IoC & Auto-Wiring: Reflection-based Dependency Injection container resolving nested contracts and singletons.
  • Tri-Phase Pipeline: Strict separation of Request lifecycle (Routing → Middleware Pipeline → Controller).
  • Database & Active Record: Query builder, migrations engine, model relations, and database seeders.
  • Asynchronous Queues: Job dispatchers, background workers, and observer event lifecycles.

Creator // Go Ecosystem

Blue GO Framework

A lightweight, high-performance Go web framework for building robust REST APIs with native concurrency, clean binding, and production-ready middleware.

  • Tree-Based Routing: Fast route grouping, parametric dispatching, and strict URL normalization.
  • Safe Type Binding: Strong JSON/Query payload decoders with integrated validation rules.
  • Resilience Pipeline: Built-in panic recovery with stack traces, structured logging, and CORS.
  • Graceful Teardown: Intercepts OS signals (SIGINT, SIGTERM) to drain active connections without data loss.
